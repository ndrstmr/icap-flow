42/**
43 * The calls of the client to its file driver: worker processes of amphp/parallel, one set per event loop, whatever
44 * driver the application configured for its own files. Only these are known to give a regular file a size and an end;
45 * a blocking driver would hold the event loop with the first open.
46 *
47 * A worker that hangs in the operating system does not answer, and no cancellation reaches it. Each call therefore
48 * runs in a fiber of its own and the operation only stops waiting for it; the call stays in the worker. It holds one
49 * of {@see MAX_PENDING} places until the driver has returned, not until the wait is over, and so does the close of a
50 * file. A caller that finds no place waits for one as long as its operation lives, and sends nothing to the driver,
51 * and a call whose operation ended while it waited or was scheduled does not start.
52 *
53 * The type of a path is looked up by a worker of its own. The workers of the files are leased to them for as long as
54 * they are open, so a lookup that waited for one would wait for the end of scans that wait for the places it holds.
55 *
56 * @internal
57 */

232        $cancellation->throwIfRequested();

244            if (isset($this->waiting[$turn])) {
