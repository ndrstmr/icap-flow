29/**
30 * Public contract for ICAP clients.
31 *
32 * Implementations are async-native and return Amp Futures. The synchronous
33 * decorator {@see SynchronousIcapClient} awaits those Futures behind a
34 * blocking facade.
35 *
36 * Every method takes an optional {@see Cancellation} so a caller can
37 * abort an in-flight scan from the outside (e.g. when an upstream HTTP
38 * upload has been aborted). A call ends at the first of three things: the
39 * caller's cancellation, which stays an `Amp\CancelledException` and wins
40 * when more than one applies; the end of the operation
41 * ({@see Config::getOperationTimeout()}, fixed when the method is called and
42 * covering every phase, and in the retry decorator every attempt and
43 * pause); and the limit of a phase ({@see Config::getStreamTimeout()}, the
44 * TLS handshake, the start of the answer). The last two are an
45 * {@see \Ndrstmr\Icap\Exception\IcapTimeoutException}. An expired call
46 * closes its socket and its file handle. Code that holds the event loop and
47 * does not return (a request-body producer, a slow cache) cannot be
48 * interrupted; the end is looked at when control comes back, and a result
49 * that comes in after it is not returned. A call into the operating system
50 * that hangs does not hold the loop, but is not interrupted either: the
51 * operation ends, and the file is closed when the call returns.
52 *
53 * Expected operational failures ({@see \Ndrstmr\Icap\Exception\IcapExceptionInterface})
54 * fail the returned Future, also when the answer comes from the OPTIONS cache;
55 * only invalid arguments throw at the call. What the code you pass in throws
56 * (producer, logger, strategy, cache, connector) passes unchanged.
57 */
