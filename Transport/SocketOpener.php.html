36/**
37 * Opens the connection to an ICAP server in the two phases it has, each with a limit of its own (M10): the TCP
38 * connection within `socketTimeout`, and, with a TLS context, the handshake within `tlsHandshakeTimeout`. The
39 * handshake is a phase of its own because it can hang on a server that accepts the connection and says nothing, and
40 * `Socket\connectTls()` has no limit for it but the cancellation of the whole call.
41 *
42 * Otherwise it does what `connectTls()` does: the peer name of the TLS context is the host when it has none. The
43 * cancellation it is given ends both phases and stays an `Amp\CancelledException`; only the limit of the handshake is
44 * an {@see IcapTimeoutException}. A connection that cannot be made, a failed handshake or a stream that breaks while
45 * it is set up is an {@see IcapConnectionException} with the amphp exception as its cause. One place for the three
46 * ways to open a connection (transport, pool, null pool).
